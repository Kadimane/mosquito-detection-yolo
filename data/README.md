# Dataset

The project will use a real mosquito image dataset whose license explicitly
permits the intended research and development use. Before acquiring or using any
images, the dataset source, license terms, attribution requirements, and any
redistribution restrictions must be reviewed and documented.

No dataset has been downloaded or added to this repository. Keep original
dataset files in `data/raw/` and any prepared copies in `data/processed/`;
dataset contents are excluded from Git by the project `.gitignore`.
